protocol; see the `LICENSE` file of each repository). The project owner intends to offer hosting of nodes and may need to offer the
code under additional terms (for example a commercial license for companies that cannot accept the AGPL)
or to move a package to another license. Without this agreement every past contributor would have to be
asked. A sign-off (DCO) alone would not allow that.
